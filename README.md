# ГӀулакх

ГӀулакх — исследовательская система собственного сетевого транспорта с Android-клиентом и серверной частью.

## Состояние

Проект находится на ранней стадии разработки. Текущий репозиторий содержит архитектурный фундамент и спецификации; он не является готовым VPN-продуктом и пока не должен использоваться для защиты реального трафика.

## Компоненты

- `server/` — серверная служба и управление клиентскими сессиями.
- `crates/protocol/` — общие типы и кодирование протокола.
- `android/` — Android-клиент на Kotlin.
- `docs/` — архитектура, модель угроз и спецификация протокола.

## Принципы

- криптографические примитивы не разрабатываются самостоятельно;
- никакого общего встроенного секрета для всех клиентов;
- fail-closed при ошибках аутентификации и криптографии;
- явное разделение управляющего канала и передачи пользовательских данных;
- воспроизводимые сборки, тесты и проверяемые конфигурации;
- транспортные реализации подключаются через стабильные интерфейсы.

## План

1. Зафиксировать модель угроз и wire-протокол.
2. Реализовать серверную управляющую плоскость и тесты.
3. Добавить передачу датаграмм и TUN-маршрутизацию.
4. Подключить Android `VpnService` к транспортному ядру.
5. Провести интеграционные, нагрузочные и сетевые испытания.

## Сборка

См. инструкции в каталогах компонентов. Полноценная сборка Android-приложения и интеграционная проверка будут добавлены по мере реализации.
