# Ghulakh (ГӀулакх)

Ghulakh (ГӀулакх) — исследовательская система собственного сетевого транспорта с Android-клиентом и серверной частью.

## Состояние

Проект находится на ранней стадии разработки. Реализованы управляющий QUIC-канал, транспортный клиент, бинарный формат IP-датаграмм и опциональный серверный IPv4 TUN с базовой ACL. Android VpnService уже связывает локальный TUN с JNI-транспортом; запуск разрешается только при включённом серверном IPv4 TUN. Серверный forwarding выключен по умолчанию. Это не готовый VPN-продукт и его нельзя использовать для защиты реального трафика.

## Компоненты

- `server/` — серверная служба и управляющий QUIC-канал.
- `crates/protocol/` — общие типы и кодирование протокола.
- `crates/transport/` — переиспользуемый QUIC-клиент с проверкой доверенного сертификата, аутентификацией, API IP-датаграмм и JNI-мостом для Android.
- `android/` — Android-клиент на Kotlin с Keystore-хранилищем и JNI-фасадом.
- `docs/` — архитектура, модель угроз, спецификация протокола и статус реализации.

## Принципы

- криптографические примитивы не разрабатываются самостоятельно;
- никакого общего встроенного секрета для всех клиентов;
- fail-closed при ошибках аутентификации и криптографии;
- явное разделение управляющего канала и передачи пользовательских данных;
- воспроизводимые сборки, тесты и проверяемые конфигурации;
- транспортные реализации подключаются через стабильные интерфейсы.

## План

1. Подключить Android `VpnService` к JNI-транспорту и локальному TUN.
2. Добавить восстановление соединения и адаптацию MTU.
3. Реализовать IPv6 и управляемые сетевые ACL.
4. Провести CI, интеграционные, нагрузочные и сетевые испытания.
