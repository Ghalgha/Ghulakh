# Текущий статус

Дата фиксации: 2026-11-10.

## Есть в репозитории

- документация архитектуры, протокола и модели угроз;
- Rust workspace и базовые типы контрольных сообщений;
- локальный HTTP control API с проверкой bearer-токена;
- минимальный Android-проект с экраном-заглушкой и объявлением VpnService.

## Не реализовано

- QUIC/TLS транспорт;
- защищённый provisioning, ротация и отзыв credentials;
- постоянное хранилище устройств и полноценное управление сессиями;
- TUN на сервере, маршрутизация и forwarding IP-пакетов;
- обмен пользовательскими датаграммами;
- интеграция Android с Rust transport core;
- полноценный UX и CI.

## Ограничения безопасности

Серверный HTTP API — только локальная разработческая заглушка. Не выставлять его в публичную сеть: TLS/QUIC, безопасное хранение credentials и полноценное управление сессиями ещё не реализованы. Токен пригоден только для локальных тестов на loopback.

Android VPN service пока не создаёт TUN-интерфейс и не перехватывает трафик.

## Следующий этап

1. Выбрать и зафиксировать Rust QUIC-библиотеку с TLS 1.3.
2. Перенести аутентификацию на защищённый QUIC stream.
3. Реализовать provisioning, rotation и revocation credentials.
4. Добавить TUN и транспорт датаграмм после threat-model review.
5. Добавить интеграционные тесты и CI.
