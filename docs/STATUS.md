# Текущий статус

Дата фиксации: 2026-11-10.

## Реализовано в репозитории

- Rust workspace и общие типы управляющего протокола;
- QUIC-сервер на TLS 1.3 с обязательной проверкой сертификата на стороне клиента;
- ALPN `ghulakh/1`;
- аутентификация индивидуальным высокоэнтропийным credential в управляющем потоке;
- сравнение хешей credential с constant-time equality;
- случайный идентификатор сессии;
- ограничение размера управляющих сообщений;
- минимальный Android-проект и объявление Android VpnService;
- документация архитектуры, протокола и модели угроз.

## Не реализовано

- выпуск, хранение, ротация и отзыв нескольких credentials через административную плоскость;
- устойчивое хранилище устройств и сессий;
- QUIC DATAGRAM для пользовательских пакетов;
- TUN на сервере, маршрутизация и IP forwarding;
- Android QUIC-клиент и интеграция с Rust transport core;
- автоматическая проверка сертификата/публичного ключа на Android;
- CI, fuzzing и интеграционные сетевые тесты.

## Ограничения безопасности

Текущая аутентификация использует один bootstrap credential из переменной окружения и предназначена только для разработки. Не использовать один credential для нескольких устройств и не передавать его по незащищённым каналам. Для эксплуатации необходимы provisioning, ротация и отзыв.

Сервер использует QUIC/TLS 1.3, но клиентская проверка TLS ещё не реализована в Android. Пока нет клиентского приложения с транспортом, сервер не является законченным сервисом. Пользовательские IP-пакеты не туннелируются.

## Локальный запуск сервера

Сгенерировать или получить сертификат и приватный ключ в PEM. Для публичного сервера использовать сертификат, которому доверяют клиенты; не отключать проверку сертификата. Задать:

- `GHULAKH_BOOTSTRAP_TOKEN` — случайный credential длиной не менее 32 символов;
- `GHULAKH_TLS_CERT` — путь к PEM chain;
- `GHULAKH_TLS_KEY` — путь к PEM private key;
- `GHULAKH_QUIC_BIND` — UDP bind address, по умолчанию `0.0.0.0:4433`.

Открыть UDP-порт, указанный в `GHULAKH_QUIC_BIND`.
