# Протокол: начальная спецификация

Статус: draft, не является стабильным wire-стандартом.

## Транспортный уровень

- QUIC и TLS 1.3 реализуют шифрование, целостность, согласование ключей и защиту транспорта от replay.
- Клиент проверяет цепочку сертификата и имя сервера.
- Отключение проверки сертификата запрещено.
- 0-RTT для изменяющих состояние команд отключён.

## Идентификация

Каждое устройство получает уникальный случайный credential. Сервер хранит только проверочное представление секрета, если выбранная схема аутентификации это допускает. Credential ограничивается конкретным устройством, может быть отозван и ротирован.

## Управляющие сообщения

Каждое сообщение имеет:
- версию протокола;
- тип сообщения;
- ограниченную длину тела;
- идентификатор запроса для сопоставления ответа.

Сервер обязан отклонять неизвестные версии, некорректные типы, превышение лимитов и сообщения с недопустимыми переходами состояния.

## Датаграммы пользовательских данных

Планируемый формат должен включать версию и тип полезной нагрузки. Максимальный размер определяется безопасным MTU и не должен приводить к IP-фрагментации QUIC-пакетов. Точные поля будут зафиксированы до реализации совместимых клиентов и сервера.

## Совместимость

Изменения wire-формата сопровождаются увеличением версии или согласованным расширением. Неизвестные критические расширения отклоняются.
